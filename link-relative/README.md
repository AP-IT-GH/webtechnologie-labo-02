**Basis**

* Maak een index.html pagina. Voeg er wat dummy-content op toe.
* Maak een about.html pagina die zich naast de index.html pagina bevindt. Voeg er ook wat dummy-content op toe.
* Voeg een link toe in de index.html pagina die verwijst naar de about.html pagina. Gebruik hiervoor een relatieve link.
* Voeg een link toe in de about.html pagina die verwijst naar de index.html pagina. Gebruik hiervoor een relatieve link.

**Uitbereiding**
* Plaats de about.html nu in een submap van de map waar index.html zich bevindt. Pas de links in beide pagina's aan zodat ze nog steeds naar elkaar verwijzen. Gebruik hiervoor relatieve links.
